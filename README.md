# EPIS — Frontend

Frontend do sistema EPIS, desenvolvido utilizando React e Vite.

## Tecnologias

- React
- Vite
- JavaScript
- CSS
- ESLint
- Prettier

## Instalação

Clone o repositório e instale as dependências:

```bash
npm install
```

## Desenvolvimento

Para iniciar o servidor de desenvolvimento:

```bash
npm run dev
```

## Verificação do código

Para executar o ESLint:

```bash
npm run lint
```

Para formatar os arquivos com Prettier:

```bash
npm run format
```

## Estrutura

A organização do frontend está documentada em:

`docs/GUIA-ESTRUTURA.md`

Consulte esse documento antes de criar novas páginas, componentes, mocks ou estruturas no projeto.

## Git

O fluxo de desenvolvimento utiliza:

```text
main
  ↓
develop
  ↓
branches de trabalho
```

Consulte o `GUIA-ESTRUTURA.md` para as regras de branches, commits e Pull Requests.
